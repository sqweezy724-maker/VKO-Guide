# VKO Guide - Сводка изменений

## 🎯 Что было добавлено

### 1. AI Ассистент (туризм ВКО)
**Файлы:**
- `src/app/components/ai-chat.tsx` - основной компонент чата
- `src/app/components/ai-chat-button.tsx` - плавающая кнопка

**Возможности:**
- Отвечает только на вопросы о туризме в ВКО

**Как использовать:**
- Нажмите на кнопку с иконкой сообщения в правом нижнем углу
- Задайте вопрос о туризме в ВКО
- Получите ответ от AI гида

### 2. Регистрация без паролей
**Файлы:**
- `src/app/components/auth-modal.tsx` - модальное окно регистрации
- `src/app/db.ts` - обновленная база данных

**Возможности:**
- Гостевой режим (прогресс сохраняется локально)
- Регистрация через email + имя (без пароля!)
- Выбор из 10 аватаров
- Автосохранение настроек

**Как работает:**
- При первом запуске появляется выбор: Гость или Регистрация
- В гостевом режиме все работает, но данные только локально
- При регистрации указывается email и имя - всё!

**Как работает:**

## ⚠️ Что нужно настроить для production

🔧 Для production рекомендуется:
1. Вынести API ключ Claude в переменные окружения
2. Добавить backend для синхронизации прогресса между устройствами
3. Создать keystore для подписи APK
4. Настроить аналитику (опционально)

## 📱 Компиляция APK

**Метод 1: Android Studio (рекомендуется)**
1. `npm run build`
2. `npx cap sync android`
3. `npx cap open android`
4. Build → Build APK

**Метод 2: Командная строка**
1. `npm run build`
2. `npx cap sync android`
3. `cd android && ./gradlew assembleDebug`

**Результат:** `android/app/build/outputs/apk/debug/app-debug.apk`

## 🐛 Известные особенности

1. **AI чат требует интернет** - работает через API Claude
2. **Геолокация на Android** - требует разрешение в настройках
3. **Данные локальные** - без backend нет синхронизации между устройствами
4. **APK размер** - debug ~15MB, release ~10MB

## 💡 Советы

1. **Разработка**: Используйте `npm run dev` + Chrome DevTools Device Mode
2. **Тестирование**: Эмулятор Android Studio или физическое устройство
3. **Production**: Всегда signed release APK для публикации
4. **Коммиты**: Используйте примеры из `GIT_COMMITS.md`

## 📞 Если что-то не работает

1. **Проверьте версии**: Node 18+, Java 17+, Android SDK 33+
2. **Очистите кэш**: 
   ```bash
   rm -rf node_modules
   npm install
   cd android && ./gradlew clean
   ```
3. **Проверьте логи**: `adb logcat` для Android
4. **Читайте** `SETUP_GUIDE.md` - там всё подробно
